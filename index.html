Features
Everything a trip plan needs

Eight specialist agents, each an expert in their domain, assembled into a single streaming response.

⚡

Real-time streaming

Results stream section by section via Server-Sent Events. No spinner waiting for the full response — flights appear while hotels are still generating.

🤖

8 specialist AI agents

Flights, hotels, activities, visa, SIM cards, forex, transport, and tips — each agent is purpose-built with its own system prompt and runs in parallel.

📅

Day-by-day itinerary

A synthesis agent combines hotel neighbourhoods and ranked activities into a coherent daily schedule, not just a list of things to do.

🎯

Relevance-ranked activities

Activities are scored with sentence-transformers cosine similarity against your stated interests. A foodie gets different rankings than a museum-goer.

🔒

Secure multi-user auth

JWT HS256 tokens, bcrypt passwords, admin-created accounts with forced first-login password change. Role-based access for admin operations.

💾

Save and revisit plans

Authenticated users can save any trip plan and return to it later. Plans are stored in SQLite with automatic Cloud Storage backup every 5 minutes.

Architecture
Three-phase orchestration

Static data first, eight agents in parallel, then synthesis — designed so the user always sees something within one second.

Phase 0

Static lookup tables

Visa categories, SIM basics, country tips, and transport modes come from pre-computed tables and stream to the browser before any AI call starts.

< 1 second
Phase 1

8 agents in parallel

  • FlightsAgent
  • HotelsAgent
  • ActivitiesAgent + relevance scoring
  • VisaAgent
  • SimAgent
  • TipsAgent
  • GettingAroundAgent
  • ForexAgent
8 – 15 seconds
Phase 2

Itinerary synthesis

The ItineraryAgent takes hotels and ranked activities and produces a day-by-day plan. 60s timeout with template fallback for resilience.

5 – 10 seconds

Quick Start
Up and running in 5 minutes

Clone, configure, start.

# 1. Clone the repository
git clone https://github.com/rupakc/travel-planner.git
cd travel-planner

# 2. Configure environment
cp .env.example backend/.env
# Edit backend/.env: set ANTHROPIC_API_KEY, JWT_SECRET_KEY, ADMIN_PASSWORD

# 3. Start with Docker Compose
docker compose up --build

# Frontend: http://localhost:8080
# Backend API: http://localhost:8001
# API docs: http://localhost:8001/docs

For non-Docker setup, detailed configuration, and GCP deployment see the project wiki.
