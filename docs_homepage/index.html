Features
Everything a trip plan needs

From visa requirements to day-by-day schedules, each piece of your journey is handled by an agent purpose-built for that exact domain.

⚡

Real-time streaming

Results stream section by section via Server-Sent Events. Flights appear before hotels finish generating — no blank screen waiting.

🤖

21 specialist agents

Flights, hotels, activities, events, visa, SIM cards, forex, weather, packing list, emergency card, places to see, layovers, chat and more — each with its own system prompt, running in parallel.

📅

Intelligent itinerary

A synthesis agent cross-references hotel neighbourhoods and ranked activities to build a coherent day-by-day schedule, not just a list.

🎯

Interest-aware ranking

Activities are scored with sentence-transformer cosine similarity against your interests. A foodie sees different results than a museum enthusiast.

🔒

Safety & emergency card

Emergency numbers, nearest international hospitals, your country's embassy, 10 survival phrases in the local language, and local laws to know — printable in one click.

🏗

Surprise Me — destination discovery

No destination in mind? Describe your budget and interests and get 5 personalised suggestions with visa status, cost estimates, and flight durations. One click to plan.

📋

Smart packing list

A personalised checklist built from your destination, weather forecast, and planned activities. Essential items flagged; check off items and they persist across sessions.

📈

Flight price advisor

Whether current prices are above or below typical for your route, when to book, and an SVG sparkline showing the historical price trend — based on training data patterns.

🕐

Timeline view

See your itinerary as a visual morning / afternoon / evening grid with weather for each day — not just a list, but a proper calendar you can scan at a glance.

🔒

Secure multi-user auth

JWT HS256 tokens, bcrypt passwords, admin-created accounts with forced first-login password change and role-based access control.

💾

Save & revisit plans

Authenticated users can bookmark any trip plan. Stored in SQLite with automatic Cloud Storage backup every 5 minutes for durability.

🗺

Multi-city journeys

Paris → Rome → Barcelona in one search: flights per leg with one pick each, per-city coverage in every section, weather per stay, and your exact stop order guaranteed throughout.

💬

Conversational advisor

Chat answers travel questions instantly from the model's own expertise, plans full trips with live per-section progress, and re-runs only the affected sections when you say “make it cheaper”.

🧠

Taste Graph personalization

The app learns your style from what you select — non-stop flights, boutique hotels, food-first activities — and ranks matching options higher on every future search. No forms.

🖼

Shareable trip card

Every saved plan gets a public share page with the complete trip — flights per leg, hotel, full itinerary with your notes — downloadable as a single full-page PNG.

Architecture
Three-phase orchestration

Static data first, 11 agents in parallel, then itinerary synthesis — designed so the user always sees something within one second of submitting. Results stream section by section rather than making you wait for everything at once.

0

Static lookup

Visa categories, SIM basics, country tips, emergency numbers, transport modes, and the Travel Confidence Score come from pre-computed tables — no AI needed, no waiting.

< 1 second
1

12 parallel agents

  • FlightsAgent (per-leg on multi-city)
  • HotelsAgent
  • ActivitiesAgent
  • PlacesAgent & EventsAgent
  • VisaAgent & SimAgent
  • TipsAgent & ForexAgent
  • GettingAroundAgent
  • WeatherAgent
  • EmergencyCardAgent
  • + PricingAdvisorAgent (deferred)
  • + PackingListAgent (deferred)
8 – 15 seconds
2

Synthesis

The ItineraryAgent ingests hotels and ranked activities and produces a structured day-by-day plan (in your exact stop order on multi-city trips). The StressTestAgent then audits it adversarially — pacing, timing, visa deadlines, weather clashes, budget. 60 s timeout with template fallback for resilience.

5 – 15 seconds
Agent System
Meet the specialists

Every agent runs independently, has its own retry logic, and writes to its own SSE event key — so a single slow API never blocks the rest.

✈

FlightsAgent

Routes, airlines, approximate fares, and booking tips for your dates.

🏠

HotelsAgent

Accommodation options by neighbourhood, star rating, and budget range.

🏞

ActivitiesAgent

Things to do, ranked by cosine similarity to your stated interests.

📍

Must-visit landmarks, temples, museums, and viewpoints with real ratings and links via Serper + Claude synthesis.

📄

VisaAgent

📲

SimAgent

Local SIM card options, data plans, and coverage by carrier.

💲

ForexAgent

🚌

GettingAroundAgent

💡

TipsAgent

Emergency numbers, nearest international hospitals, embassy details, 10 local survival phrases, and critical laws. Printable.

PricingAdvisorAgent

Analyses flight prices vs historical patterns and tells you whether to book now or wait, with an SVG sparkline trend chart.

🎒

PackingListAgent

DiscoveryAgent

Quick Start
Up and running in 5 minutes

Docker Compose handles the full stack. Three commands and you're done.

1

Clone the repository

Get the source code onto your machine.

2

Configure environment

Copy the example env file and set your Anthropic API key, a JWT secret, and an admin password. That's all that's required to start.

3

Start with Docker Compose

Builds both backend and frontend containers, wires them together, and exposes the app on port 8080.

# 1. Clone
git clone https://github.com/rupakc/travel-planner.git
cd travel-planner

# 2. Configure
cp .env.example backend/.env
#    Set ANTHROPIC_API_KEY, JWT_SECRET_KEY, ADMIN_PASSWORD in backend/.env

# 3. Run
docker compose up --build

# Frontend  → http://localhost:8080
# API       → http://localhost:8001
# API docs  → http://localhost:8001/docs

For non-Docker setup, detailed configuration options, and GCP Cloud Run deployment see the project wiki.
