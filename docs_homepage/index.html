What's new
Recent highlights

Shipped in October 2026. The changelog lists every merged pull request.

🌍

Comprehensive place data

Type “Milano”, “Portland, ME” or “Zermatt” and get the right airports, from 162,014 GeoNames places and 4,014 OurAirports airports, resolved locally. Ambiguous names like “Valencia” are left unresolved rather than guessed.

📅

Fare calendar

The cheapest live fare for departures three days either side of your dates, with the trip length kept the same, plus Google Flights' own low / typical / high price verdict.

💰

Budget planner

Split the budget into flight, stay and activity shares per person and see at once which hotels, fares and activities fit. Runs entirely in the browser.

⚖

Trip comparison

Compare two or three destinations side by side: estimated cost, flight, hotel, weather, visa and a Travel Ease grade, with the best value in each row marked.

🕐

Timed itinerary

Every activity gets an estimated start and end time, with travel time from the previous stop. Times follow your edits and carry into calendar export and shared plans.

✅

Verification labels

Each section says how much of it is backed by evidence: Verified, Partly verified, AI-generated, or Check details when the AI disagrees with curated reference data.

✋

Drag-and-drop itinerary

Move, swap and remove activities with drag-and-drop or the keyboard, add notes and edits, then re-check the edited plan with the health-check agent.

Features
Everything a trip plan needs

Each part of the journey is handled by an agent built for that domain, and the results arrive as soon as each one finishes.

⚡

Real-time streaming

Results stream section by section via Server-Sent Events, parsed in a Web Worker. Static reference data appears within a second; AI results replace it as they finish.

🤖

22 agent definitions

Flights, weather, hotels, activities, places, walking tours, events, visa, SIM, tips, emergency card, transport, forex, packing, pricing, itinerary, stress test, discovery, layovers and chat — each a prompt file you can edit.

📅

Itinerary you can shape

A synthesis agent builds the day-by-day plan from hotels and activities. Rearrange it, edit slots, add notes, view it as cards, a timeline or a map, then run the health check.

🎯

Three ways to search

Plan a known route with up to three stops, let “Surprise me” suggest five destinations, or compare two or three side by side. Recent searches are one click away.

📋

My Plan

Pick flights, hotels, activities and itinerary slots into a plan, see where the money goes, export to your calendar or a printable PDF, and save it — or add the best-value package in one click.

🔗

Share links

Every saved plan can get a public read-only link with the whole trip, without personal details, downloadable as a full-page PNG.

🗺

Multi-city journeys

Paris → Rome → Barcelona in one search: flights per leg, per-city coverage in every section, weather per stay, and your stop order kept throughout.

💬

Conversational advisor

Chat answers travel questions from the model's own knowledge, plans whole trips with a map and day cards, and re-runs only the affected parts when you say “make it cheaper”.

🧠

Taste Graph

Learns your style from the plans you save — non-stop flights, boutique hotels, food-first activities — and ranks matching options higher. Preferences and the search form stay in sync.

🛡

Safety & emergency card

Emergency numbers per city, your embassy, hospitals, survival phrases and local laws, checked against curated numbers and printable in one click.

🔒

Accounts and limits

JWT and bcrypt, admin-created accounts with temporary passwords, an admin page, a feedback widget, and per-user rate limits on every AI endpoint.

💾

One small database

Everything lives in a single SQLite file, with optional Cloud Storage backup every 60 seconds. Place data seeds itself on first start in about two seconds.

Architecture
Three-phase orchestration

Static data first, thirteen agents in parallel, then itinerary synthesis and an adversarial audit — so something useful is on screen within a second of submitting.

Agent System
Meet the specialists

Each agent is a prompt file plus a small Python class. All of them share one execution path with retries, a concurrency cap and JSON parsing, and each streams to its own section.

✈

Flights

Live Google Flights fares via SerpAPI when configured, AI estimates otherwise; one search per leg on multi-city trips.

🏠

Hotels

Options across luxury, premium, mid-range and budget tiers, with links checked online.

🏞

Activities

Things to do, each scored 0–1 for relevance to your interests and sorted by it.

📍

Places to See

Landmarks, museums and viewpoints, using Google Places data via Serper when configured.

🚶

Walking Tours

Free tours crawled from GuruWalk, FreeTour.com, FreeWalkingTour.com and SANDEMANs; the model only picks and explains them.

🎉

Events

Festivals, concerts and markets during your dates.

📄

Visa

Entry requirements for your nationality, checked against a curated visa table.

📲

SIM

Local SIM cards and global eSIMs with data plans.

💲

Forex

Exchange rates from parallel web searches, where to exchange, and card, cash and ATM advice.

🚌

Getting Around

Metro, buses, taxis, ride-hailing and inter-city transport.

💡

Tips

Etiquette, safety, scams and money tips for the destination.

⛅

Weather

Open-Meteo forecast for trips up to 16 days out; a seasonal estimate beyond that.

🛡

Emergency Card

Emergency numbers, embassy, hospitals, phrases and local laws. Printable.

📈

Pricing Advisor

Whether fares look high or low for the route and when to book, with a sparkline.

🎒

Packing List

A checklist built from the destination, the forecast and your activities.

🗓

Itinerary

Day-by-day plan with morning, afternoon and evening slots, durations and coordinates.

🩺

Stress Test

Audits the finished plan for pacing, timing, visa and weather problems, and re-checks your edits.

🌎

Discovery

“Surprise me”: five destinations with visa status, cost range and flight time from your origin.

Quick Start
Run it on your machine

There is no hosted instance; the app runs locally. You need an Anthropic API key, and Docker or Python 3.12 with Node 20.

1

Clone the repository

Get the source code onto your machine.

2

Provide your keys

Export your Anthropic API key (and optionally a JWT secret and admin password) or put them in a root .env file.

3

Start with Docker Compose

Builds both containers, wires them together and serves the app on port 8080. Sign in as admin.

# 1. Clone
git clone https://github.com/rupakc/travel-planner.git
cd travel-planner

# 2. Keys
export ANTHROPIC_API_KEY=sk-ant-...
export ADMIN_PASSWORD=choose-a-password   # default: admin-dev-password

# 3. Run
docker compose up --build

# App       → http://localhost:8080
# API docs  → http://localhost:8001/docs

# Without Docker: create backend/.env with the keys, then
./start.sh   # → http://localhost:5174

Full instructions, configuration and troubleshooting are in the setup guide.

Run it, read it, build on it

Start it locally in a few minutes, swap in your own agent prompts, or redeploy it with the retained Terraform setup.
